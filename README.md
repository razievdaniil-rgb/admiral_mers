# ТехЦентр Адмирал

Демонстрационный сайт независимого сервиса Mercedes-Benz: главная, услуги и модели, история компании, контакты двух точек в Москве.

## Запуск

Node.js 22+.

```sh
npm ci
npm run dev
npm run build
npm test
```

Vite использует `/admiral_mers/` как базовый путь. Все внутренние маршруты начинаются с `#/`, поэтому прямые ссылки работают на GitHub Pages без серверных правил.

## Публикация

GitHub Actions в `.github/workflows/deploy.yml` собирает сайт после push в `main` и публикует `dist`. В Settings → Pages выбран источник GitHub Actions. Адрес: https://razievdaniil-rgb.github.io/admiral_mers/.

## Контент и изображения

- `src/data.ts` — филиалы, телефон, история, модели и услуги. Точную применимость работ, цены и сроки подтверждает сервис; автоматических рекомендаций по двигателям нет.
- `src/assets.ts` — соответствие исходных изображений из клиентской Figma. Иллюстрации машин есть только для E W213, S W222 и GLE/ML W166. Остальные кузова доступны в текстовом каталоге. Не подменяйте их фотографией другого поколения.
- `public/media/` — локальные оригинальные экспорты клиента, конвертированные в WebP с сохранением прозрачности. Сборка не зависит от временных адресов Figma.
- `src/fonts.css` — локальные латинские и кириллические подмножества Manrope и Inter (SIL Open Font License, см. пакеты Fontsource).

Шаблоны HorizonX изучены как референсы движения. Их оригинальные исходники и медиа в репозиторий не включены.

## Демонстрационная запись

Форма проверяет поля в браузере, но **не отправляет и не хранит данные**. Кнопка называется «Проверить заполнение», рядом видимое пояснение. После проверки явно сообщается, что заявка не отправлена. Модель, направление и филиал подставляются из контекста открытия. Действует ссылка звонка.

При подключении реальных заявок потребуется отдельный серверный обработчик; секреты нельзя размещать в JavaScript или в публичном репозитории. Получателя, тексты согласия и политику согласовать с владельцем сервиса до включения отправки.

## Анимации и доступность

GSAP отвечает за появление первого экрана, параллакс и раскрытие фотографий. На телефонах первый экран не закрепляется. `prefers-reduced-motion` отключает сложное движение. Модальные окна записи и списка работ используют нативный dialog: Escape, ограничение фокуса и возврат к кнопке открытия. Есть клавиатурный выбор классов, доступные списки и альтернативные тексты.

Композиция главной возвращена к клиентской Фигме: центральный автомобиль и размытые эмблемы, три объёмные карточки, две фотографии в «Кто мы», карта и услуги. История переключается по этапам с клавиатуры и кнопками. Карточки используют оригинальные иллюстрации клиента; на компьютере реагируют наклоном и светом на указатель.

На главной — живая WebGL-сцена: 3D Mercedes собирается из частиц со всего экрана, плавно появляется и движется. Модель можно вращать и сканировать поверхность. В каталоге 12 GLB-моделей, сменяющихся горизонтальной анимацией. Другой класс или кузов указывается через отдельный список. Источники и ограничения описаны в `3D-MODELS.md`.

Обе точки на главной объединены в один блок с галереями, маршрутами и записью. Фото временные, это явно указано в интерфейсе.

На компьютерах добавлен Lenis для сглаживания прокрутки, синхронизированный с GSAP. На телефонах и при reduced-motion прокрутка нативная. Открытие диалога останавливает фон; закрытие восстанавливает прокрутку. При смене страницы позиция сбрасывается без возврата к прежней цели сглаживания.

## Ограничения первой версии

- Каталог содержит основные классы и поколения, а не полную базу комплектаций и двигателей.
- 3D-модели — художественная визуализация, не техническая документация. Сканирование показывает реальную геометрию GLB, без сгенерированных механизмов в дверях.
- Бесплатная диагностика указана с уточнением условий при записи.
- Вторая точка отмечена открывающейся до 15 ноября 2026, затем отображается обычный график. Вход и точное расположение ремзоны уточняются по телефону.
- Реальных отзывов и персональных карточек команды без материалов клиента нет.

Источники для проверки данных перечислены в `SOURCES.md`. Результаты визуальной и функциональной проверки — в `QA.md`.
